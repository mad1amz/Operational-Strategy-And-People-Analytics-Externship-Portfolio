# Amazon Operational Analytics Portfolio

## Overview

This project was completed as part of an Amazon workforce analytics and operations-focused externship. The goal of the project was to analyze employee sentiment and operational pain points within fulfillment center environments using publicly available employee feedback data.

The project combined qualitative and quantitative analysis methods to identify recurring workplace challenges, uncover root causes, and propose targeted operational interventions that could improve employee experience and workflow efficiency.

---

## Business Problem

Employee attrition, burnout, communication gaps, and inconsistent management practices can negatively impact operational performance in fulfillment center environments.

This project explored:

* What operational pain points employees discuss most frequently
* How employee sentiment varies across platforms
* Which workplace issues most strongly contribute to dissatisfaction
* What intervention strategies may improve employee experience and retention

---

## Objectives

* Collect and analyze employee feedback data
* Perform sentiment analysis on employee reviews and comments
* Identify recurring workplace themes and operational pain points
* Compare sentiment trends across multiple sources
* Build actionable recommendations supported by data

---

## Data Sources

The analysis used publicly available employee feedback and review data from:

* Glassdoor
* YouTube employee discussions and testimonials
* Online employee commentary and qualitative feedback

## Project Workflow

### 1. Data Cleaning & Preparation

Prepared and standardized employee review datasets using Python and Pandas.

Key tasks included:

* Removing duplicates
* Cleaning text fields
* Formatting sentiment labels
* Combining multiple datasets
* Organizing segmented employee feedback

Relevant notebooks:

* `DataCleaning.ipynb`
* `YoutubeCleanup.ipynb`
* `FinalCleanup.ipynb`

---

### 2. Sentiment Analysis

Performed sentiment scoring and comparison across datasets to evaluate employee attitudes and workplace perceptions.

Key focus areas:

* Positive vs negative sentiment trends
* Workplace morale indicators
* Employee frustration patterns
* Cross-platform sentiment comparison

Relevant notebooks:

* `YoutubeSentimentAnalysis.ipynb`
* `GlassdoorSentimentScore.ipynb`
* `SentimentComparison.ipynb`

---

### 3. Theme & Keyword Analysis

Identified recurring workplace themes using keyword extraction and qualitative analysis.

Common themes included:

* Burnout
* Communication breakdowns
* Lack of recognition
* Leadership inconsistency
* Workload concerns
* Scheduling challenges

Relevant notebook:

* `KeywordThemes.ipynb`

---

### 4. Root Cause & Operational Analysis

Used business and operational analysis frameworks to identify underlying causes behind employee dissatisfaction.

Frameworks used:

* 5 Whys Analysis
* Root Cause Tree
* Friction Mapping
* Employee Voice Analysis

Supporting documents:

* `5 Whys Analysis.pdf`
* `Root Cause Tree.pdf`
* `Friction Map.pdf`

---

### 5. Proposed Intervention

Developed an operational intervention framework focused on improving employee communication, shift transitions, and workplace consistency.

The proposed pilot plan included:

* Team lead ownership
* Standardized communication processes
* Pilot implementation timeline
* Measurable success metrics
* Employee feedback collection

---

## Key Insights

* Employee frustration was frequently linked to communication and management consistency.
* Sentiment trends revealed recurring operational pain points across multiple platforms.
* Qualitative feedback provided deeper context beyond numerical sentiment scoring.
* Structured operational interventions may improve workflow consistency and employee experience.
